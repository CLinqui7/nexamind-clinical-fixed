# Linkare v2.0.1

## Corrección de notas de consulta

- Las notas firmadas ahora muestran un botón **Ver nota**.
- La nota completa abre en la libreta clínica en modo de solo lectura.
- Se muestran todas las secciones: notas libres, motivo, evolución, estado mental, riesgo, medicamentos, intervención, impresión clínica, plan y seguimiento.
- Las notas firmadas no pueden modificarse accidentalmente.
- Los borradores conservan el botón **Continuar** y el guardado automático.
- Al cerrar una nota firmada ya no aparece el mensaje incorrecto de “borrador guardado”.
- La vista incluye profesional, inicio, finalización, duración y versión de la nota.
- Se mejoró la adaptación para pantallas pequeñas.
