# Linkare / NexaMind Clinical v1.3.0

- Tutorial general, compacto y más estable.
- Logo Linkare incluido como identidad inicial.
- Nueva pantalla Cobros.
- Configuración de Wompi por variables de entorno o formulario local.
- Métodos de pago: Wompi, transferencia, efectivo y seguro.
- Migración Supabase para configuración y registro de pagos.
- QA estático y Selenium para login, tutorial, móvil, Cobros y permisos de secretaría.

Nota: Supabase conserva preparación SQL/env, pero la UI mantiene fallback local hasta conectar CRUD/Auth/Storage/RLS en la siguiente fase.
