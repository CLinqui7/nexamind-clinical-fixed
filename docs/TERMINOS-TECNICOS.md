# Términos técnicos y clínicos de NexaMind

## Técnicos

- **React:** tecnología que construye y actualiza las pantallas.
- **Vite:** herramienta que inicia el proyecto y crea la versión optimizada para publicar.
- **Componente:** pieza reutilizable, como un botón, tarjeta, calendario o formulario.
- **Estado:** información que cambia durante el uso, como el paciente abierto o una ventana activa.
- **Renderizar:** dibujar o actualizar una pantalla.
- **localStorage:** espacio del navegador donde esta demo guarda sus datos. No es una base clínica compartida.
- **Seed:** conjunto de datos inventados que permite probar la aplicación.
- **Build:** versión optimizada lista para Vercel.
- **Supabase:** servicio previsto para usuarios, base de datos, permisos y archivos.
- **RLS:** reglas de base de datos que limitan qué registros puede ver o modificar cada usuario.
- **OAuth:** autorización segura para conectar servicios como Google Calendar sin guardar la contraseña.
- **ICS:** archivo universal de calendario compatible con Google, Outlook y Apple Calendar.
- **MFA:** verificación adicional al iniciar sesión, por ejemplo mediante una aplicación autenticadora.

## Clínicos

- **Baseline o valor basal:** medición inicial contra la que se compara la evolución.
- **Cambio absoluto:** diferencia de puntos entre la primera y la última medición.
- **Mejoría observada:** cambio favorable durante el seguimiento. No prueba por sí solo que un medicamento lo causó.
- **Adherencia:** estimación de cuánto sigue el paciente el tratamiento indicado.
- **Funcionamiento:** capacidad para trabajar, estudiar, relacionarse, cuidarse y realizar actividades cotidianas.
- **Tolerabilidad:** qué tan manejables son los efectos observados durante el tratamiento.
- **Exposición:** tiempo durante el cual el paciente ha recibido un medicamento.
- **Asociación temporal:** un cambio ocurrió cerca del inicio o ajuste de un tratamiento; no confirma causalidad.
- **Escala clínica:** medición estructurada, como PHQ-9, GAD-7 o YMRS.
- **Aviso clínico:** señal que solicita revisión humana; no cambia el tratamiento automáticamente.
